GrainLayer — GitHub Pages site

This package contains the site in the `site/` folder.

Local preview:
1. Open `site/index.html` in a browser.
2. The hero image has an interactive before/after slider.
3. The slider uses only HTML/CSS/JavaScript and the supplied GrainLayer screenshots.

For the repository structure discussed:
GrainLayer/
├── site/
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── images/
│       ├── grainlayer-without-overlay.png
│       ├── grainlayer-with-overlay.png
│       └── grainlayer-tray-menu.png
└── ...existing project files...

GitHub Pages can later be configured to publish the `site/` folder.
No GitHub repository changes are included or performed by this package.

Visual palette: the site uses a muted sage/forest-green accent and cooler paper tones to give GrainLayer a distinct identity rather than closely echoing Deckle's warmer palette.
