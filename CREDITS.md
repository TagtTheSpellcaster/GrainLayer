# Credits

## Inspiration

GrainLayer follows a small but important chain of inspiration:

```text
Paperman.cc
    |
    | explicitly cited as an inspiration by
    v
Deckle — Akshat Katiyar
    |
    | inspiration for the Windows implementation
    v
GrainLayer
```

### Paperman.cc

**[Paperman.cc](https://paperman.cc/)** is a desktop paper-surface utility for Mac and Windows.

### Deckle

GrainLayer was directly inspired by **[Deckle](https://projects.akshatkatiyar.com/projects/deckle/)**, a macOS application created by **Akshat Katiyar**.

Deckle explicitly cites Paperman as an inspiration. GrainLayer therefore follows that lineage indirectly while remaining an independent Windows implementation.

Special thanks to Akshat Katiyar for the original idea and inspiration behind Deckle.

GrainLayer is not affiliated with, endorsed by, or an official Windows port of Deckle or Paperman.

## Development

GrainLayer was developed as an experiment in AI-assisted programming / vibe coding using ChatGPT. The code was generated and revised through dialogue, then tested and debugged iteratively on Windows.
